CONECTAR A BIBLIOTECA

Conectar celular

Siga os passos e gerencie permissões para a biblioteca do computador.

1

No Mobile, entre no Cobre ID e toque em Pedir acesso para o seu Desktop.

2

No Desktop, abra Configurações → Conta Cobre… e toque em Permitir.

3

Após permitir, o Mobile recebe o token do Server automaticamente, sem copiar códigos.

A aprovação precisa do Desktop porque é ele que compartilha a biblioteca. O Server não exibe o token.

COMO LER ESTES ESTADOS

“Online” confirma presença, não confirma acesso à biblioteca.

O Server confirma que os apps conseguem falar com o Cobre ID. O estado do áudio só aparece quando o Mobile toca uma faixa do Desktop e informa a medição. Se o celular estiver online mas sem biblioteca, confira o endereço do Server, aprove o acesso no Desktop e confirme que o Desktop também está online.

SEGURANÇA DA REDE

HTTPS para o Cobre ID

Transporte da APISenha e sessões nos aparelhos
HTTP · sem criptografia

Use um certificado TLS válido e confiável para o endereço configurado nos aplicativos. Certificados autoassinados não são confiáveis automaticamente.

Ativar HTTPS troca o protocolo da API e reinicia o Server. Depois, atualize a URL do Cobre Server no Desktop, Mobile e TV.

CÓPIA DE SEGURANÇA

Guarde suas contas e dispositivos

O arquivo criptografado inclui contas, dispositivos, sessões e a chave desta instância. Ele só pode ser aberto com a senha escolhida. Guarde o arquivo e a senha em local seguro.

Antes de restaurar, o Cobre cria uma cópia criptografada dos dados atuais junto do arquivo escolhido e reinicia o serviço.

PRÓXIMA ETAPA

Integração de biblioteca e transmissão

O Cobre Server coordena identidade, dispositivos e permissões. O Desktop entrega a biblioteca e o áudio diretamente ao aparelho pela rede local. O Server não recebe nem retransmite arquivos de música; estar online no Cobre ID não comprova, sozinho, que o Desktop está alcançável.
